GEEKS.

Belgian geek HQ. Voor wie het altijd al was.
// SCROLL FOR INTEL

Geek culture is in België allang geen niche meer — maar het wordt nog wel zo behandeld. Versnipperde communities, geïmporteerde formats, géén plek die het samenbrengt. Tot nu. Wij bouwen het Belgische platform waar geeks zich thuis voelen, online én offline.

// WAT IS GEEKS

Een Belgisch geek-platform

Een podcast, een talkshow op VRT MAX, daily content op socials, live op Twitch, events, en ooit een fysieke hub. Allemaal vanuit één crew, één plek, één stem.

// WAT IS EEN GEEK

Niet één type. Veel types.

Iemand die diep in een wereld duikt — games, films, manga, K-pop, tech, board games — en daar méér in ziet dan ontspanning. Geen niche, wel passie.

// VOOR WIE

Voor wie het altijd al was

Geeks die nooit herkenning voelden in de Belgische mainstream. Stemmen die genegeerd worden. Mensen die hun passie niet meer willen uitleggen.

// HOE WE HET DOEN

Community boven content

Drie hosts, drie classes, één crew. Geen polish die in de weg zit, geen import, geen gatekeeping. Belgische geek culture, op zijn eigen manier.
